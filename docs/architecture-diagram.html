Motor de Inteligência Artificial
Orquestra os dados do pet, do IoT e do histórico para montar o prompt dinâmico
1
getPet() — busca perfil do pet no AsyncStorage (nome, espécie, raça, idade, peso, notas)
2
fetchIoTStatus() — GET /api/status no ESP32 via WiFi local (temp, umidade, ração, última refeição)
3
buildSystemPrompt() — injeta perfil + IoT num system prompt estruturado em linguagem natural
4
callGemini() — envia system prompt + histórico (últimas 10 msgs) + nova mensagem para a API
5
Retorna texto da resposta → chat.tsx exibe na bolha "ai"
